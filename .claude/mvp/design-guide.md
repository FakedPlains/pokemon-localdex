# Pokemon LocalDex 小程序设计指南

## 1. 产品定位

Pokemon LocalDex 小程序是面向中文宝可梦玩家的一站式移动工具，将百科图鉴与对战辅助无缝整合。覆盖全 9 世代 1025 只宝可梦的完整数据，支持队伍构筑和伤害计算，形成"查资料→组队→验证"的完整闭环。

## 2. 设计风格

**「精灵球红·暖质感」融合风格**

以宝可梦经典红白色体系为基调，融合温暖质感的半透明面板、圆润药丸形元素和毛玻璃效果。既有品牌辨识度，又有精致柔和的手感。

### 2.5 字体与排版

- **字体栈**：系统默认 `-apple-system, 'PingFang SC', 'Microsoft YaHei', sans-serif`
- **标题**：16-18px, font-weight 600, color #2D2D2D
- **正文**：14px, font-weight 400, color #2D2D2D
- **辅助文字**：12px, font-weight 400, color #8A8A8A
- **数据数字**：14px, font-weight 600（种族值、编号等用半粗体突出）
- **行高**：正文 1.5，标题 1.3

### 2.6 间距体系

- **页面水平内边距**：16px
- **卡片内边距**：14-16px
- **卡片之间间距**：12px
- **区块之间间距**：20-24px
- **元素之间小间距**：8px
- **文字与图标间距**：6px

## 4. 页面规格

### 4.1 设备基准

- 设备：iPhone 16 Pro
- 屏幕尺寸：393 × 852 px
- 内容区域：393 × 808 px（扣除状态栏 44px）
- 状态栏：44px，白底
- 微信胶囊按钮：固定在内容区域右上角，设计时预留安全区

### 4.2 胶囊按钮适配策略

- 页面顶部导航区域高度 44-56px
- 左侧可放置返回按钮、页面标题
- 右上角预留 100px 宽度给胶囊按钮
- 搜索框等宽元素放在导航区下方，避免与胶囊重叠

### 4.3 通用页面结构

```

│  ├─ 功能区 ────────────────────┤ │
```

## 5. 各页面设计要点

### 5.1 图鉴首页 (home.html)

- 顶部：页面标题「图鉴」+ 搜索图标
- 搜索栏：药丸形输入框，灰色占位符"搜索宝可梦名称或编号"
- 筛选区：横向滚动的世代 chip（全部/第一世代…第九世代）+ 属性 chip
- 列表：两列网格卡片
  - 每张卡片：宝可梦图片（居中）、编号（#0001 格式，灰色小字）、中文名（主文字）、属性标签（1-2 个小药丸）
  - 卡片用毛玻璃面板样式，圆角 16px
- 底部 TabBar

### 5.2 宝可梦详情页 (pokemon-detail.html)

- 自定义导航：返回箭头 + 宝可梦名称
- Hero 区域：
  - 大图居中展示（带属性色渐变背景）
  - 编号 + 中文名 + 英文名 + 日文名
  - 属性标签（药丸形）
  - 分类 / 身高 / 体重小标签
- 特性区：圆角卡片列出特性（隐藏特性单独标注）
- 种族值：六维条形图 + 数字，条形颜色按数值分段（低红、中黄、高绿）
- 进化链：横向展示进化关系，箭头连接
- 招式表入口：卡片入口，点击进入招式表子页面

### 5.3 资料库页 (database.html)

- 顶部 Tab：招式 / 特性 / 道具（药丸形分段控件）
- 搜索栏 + 筛选（招式页有属性/分类筛选，特性页有世代筛选，道具页有分类筛选）
- 招式列表项：招式名 + 属性标签 + 分类图标 + 威力/命中/PP 数据行
- 特性列表项：特性名 + 简介摘要
- 道具列表项：道具图标 + 名称 + 分类标签 + 效果摘要
- 点击进入对应详情页

### 5.4 招式详情页 (move-detail.html)

- 自定义导航：返回 + 招式名
- Hero 区：招式名 + 属性标签 + 分类标签
- 基础数据卡片：威力/命中/PP/优先级，两列网格
- 效果说明卡片：招式效果文字
- 世代变更时间线：GenerationTimeline 样式，卡片列表展示各世代的参数变化
- 可学习的宝可梦：横向滚动的宝可梦头像网格

### 5.5 队伍构筑页 (teams.html)

- 顶部 Tab：宝可梦盒子 / 我的队伍
- **盒子 Tab**：
  - 搜索 + 新建按钮
  - 卡片列表展示已配置的宝可梦：图片 + 名称 + 属性 + 性格 + 特性 + 道具 + 4 招式缩略
  - 点击进入编辑
- **队伍 Tab**：
  - 队伍列表，每个队伍卡片展示队名 + 6 个成员头像
  - 展开后显示 2×3 成员网格，每个槽位有宝可梦图片 + 名称 + 属性
  - 新建队伍、编辑队名、添加/移除成员

### 5.6 伤害计算页 (damage.html)

- 自定义导航：返回 + "伤害计算"
- 攻击方区域：卡片面板
  - 宝可梦选择（图片 + 名称，点击弹窗选择）
  - 等级 / 性格 / 特性 / 道具 横向简洁布局
  - 招式选择（最多 4 招，药丸形标签）
- 防守方区域：同攻击方布局
- 场地设置：折叠面板，天气/场地/其他开关
- 计算结果区域：
  - 伤害数值（大字突出）
  - 百分比进度条（渐变色，绿→黄→红）
  - 详细描述文本
- 底部"计算"按钮（主色大按钮）

### 5.7 个人中心页 (profile.html)

- 顶部用户信息区：头像 + 昵称（或默认"训练家"）
- 工具入口卡片网格（2×2）：
  - 伤害计算器
  - 属性相克表
  - 速度线查询（未来）
  - 更多工具（未来）
- 设置区域：
  - 默认世代
  - 关于 Pokemon LocalDex
  - 版本信息

## 6. 交互规范

### 6.1 加载态

- 列表加载：骨架屏（skeleton），卡片形状的灰色脉冲块
- 详情加载：顶部图片区域模糊占位 + 下方内容骨架屏
- 触底加载更多：底部小型 loading 圆点动画

### 6.2 空态

- 搜索无结果：居中图标 + "没有找到相关结果" + 建议文案
- 队伍为空：大型引导图 + "创建你的第一支队伍" + 引导按钮

### 6.3 滚动与刷新

- 下拉刷新：跟随系统默认
- 无限滚动：IntersectionObserver 触发，每页 40 条
- 返回顶部：长列表滚动超过 2 屏后显示"返回顶部"悬浮按钮

### 6.4 转场

- 页面跳转：从右侧滑入（微信默认）
- 弹窗/面板：从底部滑出，带蒙层
- Tab 切换：内容区淡入
